# Lavin Kost Inventory

Buatkan saya web responsive pwa dengan theme putih gading dengan garis gold halus.

Untuk Aplikasi Inventaris Lavin Kost Purwokerto.

Aplikasi ini melakukan pencatatan edit tambah kurang untuk :

- Fasilitas utama kost.

- Fasilitas per kamar.

Fasilitas Per Kamar mencakup :

- tv

- ac

- dipan

- meja belajar

- kursi pendek

- kursi panjang

- mcb listrik

- kasur

- bantal guling

- dan bisa ditambahkan lagi diedit dan dikurangi atau (CRUD).

Total ada tiga lantai :

Lantai 1 10 kamar

Lantai 2 11 kamar

Lantai 3 11 kamar

Nama kamar 001 002 003 004 dst nya. 

Yang dimaksud fasilitas Utama kost adalah fasilitas yang dipakai bersama seperti :

Pompa air

Torent air 

Pagar

Trafo listrik utama

Kompor gas 

Dapur 1 - 2 - 3

Lampu halaman 1

Lampu halaman 2 dst nya

Access point 1 dst nya

IP Camera 1 2 dst nya

Aplikasi menggunakan database lovable.dev cloud tapi belum menggunakan user password
